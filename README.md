
# My Budget Tracker

## Project Description
My Budget Tracker is a simple web application
that helps users manage their personal finances.

## Features
- Set a monthly budget.
- Add income.
- Record expenses.
- Select transaction categories.
- Calculate total income.
- Calculate total expenses.
- Display remaining balance.
- Delete transactions.
- Save data using Local Storage.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Open the project folder in VS Code.
2. Open index.html in your browser.
3. Enter your monthly budget.
4. Add your income and expenses.
5. View your financial summary.

## Storage
The application uses browser Local Storage
to save budget and transaction information.
